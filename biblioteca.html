Captura Instantânea da Amazon
Adicione um botão na barra de favoritos do seu navegador. Ao estar em qualquer página de livro na Amazon, clique nele e o livro será capturado automaticamente (título, autor, capa, páginas, descrição) — você só precisa colar seu link de afiliado.
⚡ Instalação (1 minuto)
1
Ative a barra de favoritos no navegador
Chrome/Edge: Ctrl+Shift+B · Safari: Visualizar → Mostrar Favoritos · Firefox: Ctrl+Shift+B
2
Arraste o botão abaixo para a barra de favoritos
📚 Capturar para G20
Clique e segure e arraste para a barra de favoritos — ou use o método manual abaixo
Método manual (Chrome)
1. Botão direito na barra de favoritos → Adicionar página
2. Nome: 📚 Capturar para G20
3. URL: clique em Copiar código abaixo e cole no campo URL
3
Use o botão
Vá para amazon.com.br, abra a página de qualquer livro, e clique no favorito "📚 Capturar para G20". Uma janela vai aparecer mostrando os dados capturados. Cole seu link de afiliado e clique em salvar.
💡 Dica
Funciona em qualquer página de produto da Amazon (br, com, etc). Você precisa estar logado nesta plataforma na mesma sessão de navegador onde clica o favorito.
⚠ Importante
Permita popups deste site no seu navegador. O bookmarklet abre uma janela popup com os dados capturados.
